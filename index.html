About Me

I am a full-stack developer and CSE major with a keen interest in building high-quality, secure web applications. I specialize in designing and engineering applications that balance modern, intuitive UX with strict, production-grade web security guidelines.

Recently, I've developed platforms addressing local Bangladeshi problems. This includes **Vibora**, a localized campus-and-district community hub with zero external telemetry, and **DeshBari**, a remittance and family expense dashboard focusing on simplicity and currency statistics.

My objective is to build clean, well-tested code bases that solve real-world problems. When I'm not programming, I research client-side exploit mitigation layers, API security controls, and design trends.
